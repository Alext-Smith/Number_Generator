# Number Guessing Game

A Python command-line guessing game where the player 
tries to find a randomly generated number in three attempts.

## Features
- Random number generation between 1 and 10
- Three attempt limit with attempts counter
- Higher/lower hints after each guess
- Duplicate guess detection
- Play again option

## How to run
1. Install Python 3.x
2. Open Number Game.py in any Python editor
3. Run the file and follow the prompts

## Built with
Python 3.13 | PyCharm

## Skills demonstrated
try/except error handling, while loops, lists,
random number generation, input validation
